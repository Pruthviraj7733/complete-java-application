# Security baseline
Never commit credentials, AWS keys, kubeconfigs or cert private keys. Use role-based AWS credentials and scoped ECR IAM permissions. EKS IAM role for AWS Load Balancer Controller via IRSA; use trust policy from official docs. Pin Docker base images by digest for reproducibility and update regularly. Use SCA/CVE/secret scanning, image scanning and SonarQube gate. Restrict network access: existing NetworkPolicy only restricts ingress by port; implement a CNI that enforces NetworkPolicy, namespace selectors/ALB connectivity, plus DNS egress policies as needed. Shared ALB IngressGroup permits cross-namespace rule interaction by anyone authorized to create members: restrict admission/RBAC. Configure HTTPS/TLS, WAF as appropriate, restrictive security groups, CloudWatch logs and audit logs. Production ideally uses separate cluster/account, private nodes, non-root image, image signing and admission controls.
