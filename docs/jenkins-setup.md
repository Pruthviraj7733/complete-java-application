# Jenkins
Use a Multibranch Pipeline job, GitHub webhooks and Jenkins credentials/EC2 instance role. Agent requirements: Docker daemon access, AWS CLI v2, Trivy, SonarScanner, bash, Git. Install Jenkins plugins: Pipeline, Git, GitHub Branch Source, SonarQube Scanner. Configure SonarQube installation name sonarqube and its webhook ending /sonarqube-webhook/ on Jenkins. Store AWS credentials in an IAM role or secrets store, not SCM. Set AWS_ACCOUNT_ID, AWS_REGION, ECR_REPOSITORY in Jenkins and use protected build agents. Tag ECR images with immutable BUILD_NUMBER and record digest. UAT/PROD Jenkins pipelines only validate; deployment is via approved Git changes reconciled by Argo CD.
