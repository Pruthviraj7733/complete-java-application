# GitHub repository rulesets (manual configuration)
Settings -> Rules -> Rulesets: target dev, uat, main. Require PR before merging, review approvals (prefer one or more independent reviewers), required status checks (PR validation, Jenkins checks if published), resolved conversations, prohibit force push and deletion. Add CODEOWNERS, limit bypass roles. Enforce UAT sign-off for uat and release approver for main. GitHub App connector currently cannot edit rulesets. PR-required rulesets and status checks must be verified after enabling. NOTE: An owner cannot count their own approval as independent review; use a real reviewer.
