# Complete build and promotion sequence
PR checks -> DEV merge -> Jenkins checks filesystem with Trivy, SonarQube gate, Docker build, Trivy image scan, push immutable image to ECR -> record sha256 digest. Update DEV k8s deployment with that digest through PR, allow DEV Argo CD autosync. Promote exact same digest to UAT by controlled PR (preserve java-uat config), QA signoff, manual Argo CD sync. After UAT signoff repeat for main/java-prod, manually sync. Never merge environment-specific namespace and ingress without review. Production workloads should be isolated from DEV in separate cluster/account for truly high-risk use.
